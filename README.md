# 📊 RetailPlus - Business Analytics System

**RetailPlus** is a web-based retail management, billing, and inventory tracking application designed to streamline daily store operations and automate record-keeping for small to medium-sized retail businesses. Built as a capstone project for Savitribai Phule Pune University, it bridges the gap between daily point-of-sale activities and structured business intelligence.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, JavaScript (Responsive UI)
- **Backend:** Python (Flask Micro-framework)
- **Database:** SQLite3 (Normalized relational schema)
- **Development Tools:** Visual Studio Code, Git, GitHub

---

## ✨ Key Features

- **Role-Based Access Control (RBAC):** Strict separation of privileges between *Administrators* (full oversight of inventory, financial profit margins, staff accounts, and analytics) and *Cashiers* (dedicated POS checkout and billing interface).
- **Point-of-Sale (POS) & Automated Billing:** Fast product lookup, automatic calculation of itemized subtotals and totals, and instant generation of professional digital receipts.
- **Real-Time Inventory Synchronization:** Dynamic product catalog that tracks purchase prices, selling prices, and stock levels, automatically decrementing inventory upon every completed sale.
- **Business Analytics Dashboard:** Aggregates transaction logs to track total revenue, items sold, purchase costs, and net profit margins with weekly trend visualization.
- **Internal Support Desk:** Built-in ticketing module enabling staff to log, track, and resolve operational or technical issues.
